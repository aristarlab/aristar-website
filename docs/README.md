# 문서 체계

| 디렉터리 | 용도 | 파일명 규칙 |
|---|---|---|
| `decisions/` | CEO 결정 기록 (불변) | `YYYY-MM-DD-<주제>.md` |
| `reports/` | 업무 완료 보고서 | `YYYY-MM-DD-<주제>.md` |
| `plans/` | 주관 본부 업무 계획·명세 | `YYYY-MM-DD-<주제>.md` |

- 결정 문서는 수정하지 않는다. 번복 시 새 파일을 만들고 이전 문서를 링크한다.
- 보고서에는 실패한 검증도 그대로 적는다.
- 작성은 `/report` 스킬로 한다.
