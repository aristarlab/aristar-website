- 일자: 2026-11-06
- 결정자: CEO
- 상태: 확정
- 주관: 전략기획본부(명세) · IT본부(구현)
- 선행 결정: [웹사이트 스택과 메일 분류 기반](2026-11-06-web-stack-and-mail-platform.md) · [메인 페이지 재구성의 구현 시점 분리](2026-11-06-main-page-rebuild-sequencing.md)

## 배경

CEO 지시로 해외 유명 웹사이트 UI/UX를 참고해 메인 페이지를 재구성했다. 벤치마킹 명세(`docs/plans/2026-11-06-design-bench-main-page.md`)가 IT본부장 검수를 통과한 뒤, `frontend-design` 지침으로 한 차례 더 검토한 결과 **승인된 명세가 생성형 디자인의 기본값에 해당하는 특징을 갖고 있음**이 드러났다.

- Noto Sans KR — 한글 웹의 기본값. 어느 프로젝트에나 손이 가는 선택
- 모든 제품 타일 위의 eyebrow 라벨 — "template chrome"에 해당
- 섹션별 fade-and-slide-up 등장(명세 9순위) — 생성형의 전형으로 직접 지목되는 패턴
- 그리고 **자기모순**: "조용한 소프트웨어"를 주장하는 문장을 92px로 외치고 있었다

두 시각 방향을 프로토타입으로 구현해 CEO가 실물로 비교했다.

## 선택지와 결정

| | A — 쇼케이스 | B — 색인 |
|---|---|---|
| 팔레트 | Apple 계열 회색 + `#0066cc` | 잉크 단색 스케일 + 청록 신호 `#2E6354` |
| 서체 | Noto Sans KR | 고운바탕 + IBM Plex Sans KR |
| 제목 최대 | 92px | 44px |
| 구조 | 쇼케이스 타일, 가운데 정렬 | 동일 구조 색인 행, 상태는 좌측 열, 왼쪽 정렬 |
| 자간 | `clamp()` px 보간으로 보정 | `0` — 스케일을 줄여 보정 불필요 |

**결정: B안(색인).** CEO 평가 — "깔끔해 보인다".

프로토타입: `prototypes/a-showcase.html`, `prototypes/b-index.html`, 비교 하네스 `prototypes/compare.html`

## 확정된 토큰

| 토큰 | 값 | 역할 | 대비비 (on white) |
|---|---|---|---|
| `--ink` | `#0F1C24` | 제목·본문 | 17.33:1 |
| `--ink-mid` | `#45575F` | 보조 텍스트 | 7.55:1 |
| `--hairline` | `#94A3AB` | 선 **전용** | 2.60:1 — 텍스트 금지 |
| `--paper` | `#F4F6F6` | 면 | — |
| `--page` | `#FFFFFF` | 바탕 | — |
| `--signal` | `#2E6354` | 링크·포커스·상태 | 6.93:1 |

전부 WCAG 상대휘도 공식으로 계산해 검증했다.

- 서체: **고운바탕**(성명문·사업명) + **IBM Plex Sans KR**(본문·UI). 두 서체가 회사의 두 축(조용함 / 소프트웨어)을 담는다. 둘 다 Google Fonts 제공 확인.
- 본문: 17px / `line-height: 1.6` / 자간 `0` / 측정폭 540px
- 라운드: **상호작용 표면에만.** 라운드값이 "누를 수 있음"을 뜻한다
- 비트리거 모션: **없음**

### 근거의 성격 (혼동 금지)

- `line-height: 1.6`은 **설계 선택이다.** 한글 전용 행간 수치를 제시하는 1차 자료는 없다는 판정을 유지한다. 증거로 주장하지 않는다.
- 측정폭 540px은 전단짜기 "활자틀 너비 25~35배" 기준의 17px 환산(425~595px)과 16px 환산(382~561px) 양쪽에 모두 들어가는 값이다.
- 자간 `0`은 리서치에서 확인된 Pretendard 공개 가이드(중간 이하 제목 0px)에 근거한다. 44px 상한 스케일에서는 음수 자간이 필요한 구간이 없다.

## 함께 폐기되는 것

B안 채택으로 승인된 명세의 아래 항목이 **불필요해진다.**

- `h1` 자간 `clamp()` 보간식 — 스케일 축소로 자간 0
- 섹션 제목류 자간 일반화 보간식
- `animation-timeline: view()` 스크롤 등장 — 모션 0
- `prefers-reduced-motion` 강제 정지 구현 — 끌 애니메이션이 없음
- `animation-timeline` caniuse 재확인 과제
- `@supports` 폴백 설계
- 다크 타일 폐기 조치 — 타일 자체가 없어짐

## 승계되는 것

시각 방향과 무관한 항목은 전부 유효하다.

- 성숙도를 중요도로 읽히지 않게 하는 요구사항 (B안은 동일 구조 행 + 중립 상태 열로 더 강하게 충족)
- 파이프라인을 실제 HTML `<ol>`로 노출 — `role="img"` 접근성 평탄화 회피
- 360px 구간 대응
- 하드코딩 색 제거 (적용 후 0건 확인)
- `keep-all` + `overflow-wrap: break-word`, `ch` 단위 금지, `text-wrap` 자동 줄바꿈 미도입
- 제품에서 `/<슬러그>` 페이지로의 링크 — **그룹 B로 보류 중**

## 적용 범위와 보류

### 적용 완료
`index.html`을 B안으로 교체했다. 기존 파일은 git `2c438e2`에 보존되어 복구 가능하다.
`privacy.html`, `terms.html`, `CNAME`, `app-ads.txt`는 **건드리지 않았다.**

### 보류 (선행 조건 미충족)
- **"자세히 보기" 링크를 넣지 않았다.** `/esay-memory-eng` 등 서비스 페이지가 아직 없어 404가 된다. 선행 결정에 따라 Next.js 전환 후 추가한다. 각 사업 설명이 본문에 전부 들어가 있어 현재 페이지는 온전하다.
- 그 결과 **구조적 결함 1번(제품에서 상세로 가는 링크 부재)은 아직 해소되지 않았다.** 연기이지 취소가 아니다.

## 남은 불일치 — 후속 과제

`privacy.html`과 `terms.html`은 베이지 톤 + 테라코타 액센트, Fraunces + JetBrains Mono로 **메인 페이지와 전혀 다른 시각 언어**를 쓴다. 메인을 B안으로 교체해 불일치가 커졌다. 두 페이지의 토큰·서체를 B안으로 맞추는 작업이 필요하다. 법무 검토가 끝난 본문 내용은 바꾸지 않고 스타일만 교체한다.

OG 이미지가 없다. `og:image`를 비워 두었으므로 공유 카드가 빈약하다. 컨텐츠본부 제작 과제다.
